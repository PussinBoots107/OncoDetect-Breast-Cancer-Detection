UNDER THE HOOD

Python does
the thinking.

The interface is the front door. The actual classification happens in Python using scikit-learn, with Flask connecting the form to the trained models.

01

Prepare the data

Load the bundled Wisconsin dataset, map the labels explicitly, and split it into stratified training and test sets.

load_breast_cancer()
02

Train three classifiers

Scale inputs for Logistic Regression and SVM. Random Forest uses the original measurements.

scikit-learn
03

Evaluate the models

Calculate accuracy, precision, recall, and F1-score on held-out data, not training predictions.

sklearn.metrics
04

Serve a prediction

The Flask API validates the 30 values and returns the selected model's predicted class and score.

/api/predict
